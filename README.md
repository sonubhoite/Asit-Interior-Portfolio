# ASIT Enterprises — Interior Portfolio

A responsive, premium interior-architecture portfolio website built with plain HTML, CSS and JavaScript.

## Important image note
- Images inside `images/client/` were extracted from the supplied ASIT Enterprises portfolio presentation.
- Selected showcase images are loaded from Unsplash and are explicitly labelled as concept/showcase imagery in the website. They must NOT be presented as ASIT Enterprises completed projects.
- Before commercial launch, replace concept imagery with client-authorized project photographs wherever possible.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## AWS deployment
Upload the project files to an S3 bucket configured for static website delivery, then place CloudFront in front of it for HTTPS and a public shareable URL.
